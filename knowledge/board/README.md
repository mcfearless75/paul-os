# The Board

Each file = one advisor's lens: core frameworks, the questions they'd ask, what they'd push back on, and their blind spots.
These are Claude's summaries of publicly known frameworks — not quotes. Quality improves when you add real source material
(transcripts, essays, book notes) under `sources/<advisor>/` and ask Claude to refine the file from it.

To add an advisor: copy any file, keep the same headings, list it below.
